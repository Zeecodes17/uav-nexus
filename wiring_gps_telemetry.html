GPS & Telemetry Wiring

Wiring GPS modules and telemetry radios to the flight controller

GPS ↔ Flight Controller Wiring

Before You Start

  • Remove all propellers
  • Identify GPS module pinout
  • Confirm GPS voltage (5V or 3.3V)
  • Select a free UART on the FC

Standard GPS Wiring (UART)

GPS Module Flight Controller Notes
TX UART RX Cross TX → RX
RX UART TX Cross RX → TX
+5V / 3.3V +5V / 3.3V Match GPS voltage rating
GND GND Common ground required

Compass (I²C) Wiring

Compass Flight Controller
SDA SDA
SCL SCL
+3.3V / +5V +3.3V / +5V
GND GND

GPS Wiring Mistakes

  • TX connected to TX instead of RX
  • Incorrect GPS voltage
  • Using same UART as telemetry or receiver
  • Incorrect compass orientation

Telemetry ↔ Flight Controller Wiring

Before You Start

  • Identify telemetry radio voltage
  • Select a dedicated UART
  • Check antenna connection

Standard Telemetry Wiring (UART)

Telemetry Radio Flight Controller Notes
TX UART RX Always cross TX → RX
RX UART TX Always cross RX → TX
+5V / 3.3V +5V / 3.3V Match telemetry voltage
GND GND Common ground required

Telemetry Wiring Mistakes

  • TX → TX instead of TX → RX
  • Powering telemetry from battery voltage
  • Sharing UART with GPS
  • Loose antenna connection

Final Check (GPS + Telemetry)

  • GPS and telemetry use separate UARTs
  • All grounds connected
  • Voltage levels verified
  • FC powered via USB first
