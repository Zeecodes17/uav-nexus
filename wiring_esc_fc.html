ESC ↔ Flight Controller Wiring

Connecting ESC signal, ground, and power lines to the flight controller

Before You Start

  • Remove all propellers
  • Do NOT connect the battery yet
  • Verify ESC type (OPTO or BEC)
  • Identify FC motor output pins

ESC Control Cable (3-Wire)

Most ESCs use a 3-wire servo cable to communicate with the flight controller.

  • White / Yellow → Signal
  • Black / Brown → Ground
  • Red → +5V (BEC output, if present)

Standard ESC → FC Connection

ESC Wire Flight Controller Pin Notes
Signal (White / Yellow) M1, M2, M3, M4… Motor output number must match motor order
Ground (Black / Brown) GND Mandatory for signal reference
+5V (Red) +5V (optional) Connect only ONE BEC unless FC manual allows multiple

OPTO ESC vs BEC ESC

OPTO ESC

  • No red wire (no power output)
  • Requires external power module or BEC
  • Common in larger drones

BEC ESC

  • Has red +5V wire
  • Powers FC and receiver
  • Use only ONE red wire connected

Motor Output Order (Critical)

ESCs must be connected to the correct motor output pins based on the flight controller firmware (ArduPilot / Betaflight).

  • Motor 1 → M1
  • Motor 2 → M2
  • Motor 3 → M3
  • Motor 4 → M4

Motor direction and order are verified later in software.

Common Mistakes

  • Connecting multiple ESC red wires to FC
  • Skipping ground connection
  • Incorrect motor numbering
  • Powering FC directly from battery voltage

Pre-Power Checklist

  • ESC signal wires firmly seated
  • Only one +5V line connected (if BEC)
  • FC powered via USB first
  • No propellers installed
