Final Power-Up & Safety Checklist

Mandatory checks before connecting the battery and first system power-up

ABSOLUTE SAFETY RULES

  • REMOVE ALL PROPELLERS
  • Never test motors with props installed
  • Use USB power for first checks
  • Keep LiPo battery disconnected until instructed

Mechanical Check

  • Motors firmly mounted
  • No wires touching rotating parts
  • Frame screws tightened
  • ESCs securely mounted

Power Wiring Check

  • Battery polarity verified (+ / –)
  • No exposed solder joints
  • Correct wire gauge used
  • Only one BEC powering the FC

Signal Wiring Check

  • ESC signal → correct motor outputs
  • Receiver signal → correct RC input
  • GPS and telemetry on separate UARTs
  • All grounds connected

First Power-Up (NO BATTERY)

  • Connect flight controller via USB
  • Confirm FC powers up normally
  • No smoke, heat, or smell
  • Status LEDs behave as expected

Receiver Test

  • Receiver LED indicates link
  • Channels respond in software
  • Failsafe detected when transmitter off

Motor Test (NO PROPS)

  • Connect battery
  • ESCs initialize normally
  • Test motors one by one
  • Verify correct motor order
  • Verify correct rotation direction

Final Confirmation

  • No abnormal heating
  • No loose connectors
  • Battery voltage stable
  • All systems responding

Only Now Install Propellers

  • Correct CW / CCW prop placement
  • Props tightened securely
  • Clear test area
  • Ready for controlled first flight
