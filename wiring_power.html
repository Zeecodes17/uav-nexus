Power Distribution

Battery → PDB → ESCs → Flight Controller power wiring

Safety First

  • Remove all propellers
  • Do NOT connect the battery while wiring
  • Verify battery voltage and polarity
  • Use proper wire gauge for current

Main Power Path

Multirotor power systems follow a simple distribution chain:

  • Battery → Power source
  • PDB / Power Module → Distributes voltage
  • ESCs → Regulate motor power
  • Flight Controller → Powered via regulated supply

Battery to PDB

Battery Wire PDB Connection Notes
Red (+) VBAT + Check polarity twice before soldering
Black (–) GND Ground reference for entire system

PDB to ESC Power

Each ESC draws high current directly from the battery via the PDB.

ESC Wire PDB Pad Notes
Red (+) VBAT + High current line
Black (–) GND Shared ground

Powering the Flight Controller

Flight controllers must NEVER be powered directly from battery voltage.

  • Use a power module, BEC, or regulated 5V/6V supply
  • Common sources:
    • PDB BEC output
    • Dedicated power module
    • Single ESC BEC (small drones only)

Typical FC Power Inputs

FC Pin Voltage Source
POWER / PM 5–6V Power module
SERVO RAIL 5–8V BEC (check FC manual)
USB 5V Configuration only

Common Power Mistakes

  • Reversing battery polarity
  • Powering FC directly from battery
  • Using thin wires for ESC power
  • Multiple BECs connected together

Pre-Power Checklist

  • Continuity check between + and – (no short)
  • Correct wire gauge for battery and ESCs
  • FC powered via USB first
  • No motors or props spinning freely
