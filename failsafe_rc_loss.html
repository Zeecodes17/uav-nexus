RC Signal Loss

Immediate actions and decision guidance when control signal is lost. This page is intended for fast reference under stress.

1. Recognize the Situation

You are likely experiencing RC Signal Loss if:
  • Stick inputs produce no response
  • Telemetry freezes or shows signal warning
  • The aircraft continues last commanded motion

Do not assume GPS, compass, or battery failure at this stage.

2. Immediate Actions (First 5 Seconds)

Stop aggressive inputs immediately.
  • Release sticks to neutral
  • Do not toggle flight modes rapidly
  • Allow onboard failsafe logic to engage

Sudden mode changes during signal loss can worsen instability.

3. What the Aircraft May Do

Failsafe Behavior What It Means
Return to Home (RTH) Aircraft navigates back using GPS
Land Aircraft descends vertically at current location
Hold / Loiter Aircraft maintains position temporarily

You may not know which behavior is active during the event. Assume the most conservative case.

4. Battery Reality Check

If the aircraft is returning automatically, battery margin becomes critical.

Mentally assess:

  • Approximate distance to home
  • Expected cruise power
  • Remaining reserve margin

If uncertain, assume margin is tight and prepare for an off-nominal landing.

Use Return Flight Energy Check when planning or reviewing incidents.

5. If Signal Returns

Regain control calmly.
  • Stabilize attitude first
  • Avoid abrupt yaw or throttle changes
  • Do not immediately switch modes

Allow sensors and control loops to settle before continuing the mission.

6. If Signal Does Not Return

Prepare for recovery after landing.
  • Note last known heading and altitude
  • Observe wind direction
  • Mark last visible or reported position

When planning autonomous return behavior, verify feasibility using Return Flight Energy Check.

RC signal loss is survivable when handled calmly. Most losses escalate due to rushed reactions, not the failure itself.
