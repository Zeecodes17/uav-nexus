Receiver ↔ Flight Controller Wiring

Connecting RC receiver signals, power, and ground to the flight controller

Before You Start

  • Remove all propellers
  • Do NOT power from battery yet
  • Identify receiver output type (PWM / SBUS / iBUS / CRSF)
  • Check FC receiver input pins

Receiver Output Types

Type Wires Notes
PWM 3 wires per channel One signal wire per channel
SBUS Single signal wire Serial, inverted (FrSky)
iBUS Single signal wire Serial, non-inverted (FlySky)
CRSF TX + RX Bi-directional, UART required

PWM Receiver Wiring

PWM receivers use one signal wire per channel.

Receiver Flight Controller Notes
CH1 Signal RC1 / PWM1 Roll
CH2 Signal RC2 / PWM2 Pitch
CH3 Signal RC3 / PWM3 Throttle
CH4 Signal RC4 / PWM4 Yaw
+5V +5V From BEC or power module
GND GND Common ground required

SBUS / iBUS Receiver Wiring (Serial)

Serial receivers use a single signal wire for all channels.

Receiver Flight Controller Notes
SBUS / iBUS Signal RC IN or UART RX Depends on FC design
+5V +5V From BEC or FC rail
GND GND Mandatory

Signal Inversion (Critical)

  • SBUS (FrSky) signals are inverted
  • Use FC SBUS pad or inverted UART input
  • iBUS and CRSF are NOT inverted
  • Incorrect inversion = no receiver input

CRSF / ExpressLRS Wiring

CRSF requires a full UART connection.

Receiver Flight Controller
TX UART RX
RX UART TX
+5V +5V
GND GND

Common Receiver Wiring Mistakes

  • Missing ground connection
  • Using wrong UART for serial receivers
  • Incorrect SBUS inversion
  • Powering receiver from battery voltage

Pre-Power Checklist

  • Receiver powered from regulated 5V
  • Signal wire connected to correct pin
  • Common ground confirmed
  • Receiver LED indicates normal state
