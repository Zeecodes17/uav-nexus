ESC Overview

ESC (Electronic Speed Controller) controls the speed of the brushless motor.

Main Functions

  • Receives signal from flight controller
  • Regulates motor speed
  • Supplies power from battery to motor

Key Parameters

  • Current rating (e.g., 30A, 40A, 60A)
  • Voltage support (e.g., 3S–6S)
  • Firmware type
